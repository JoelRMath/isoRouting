# Turin HVAC Telemetry Dataset (Engineered Features)

A continuous, engineered multivariate telemetry dataset from a
commercial HVAC system in Turin, Italy. The dataset includes raw
mechanical sensors alongside temporal derivations (rolling volatilities,
instantaneous derivatives) designed for physical archetype extraction.

## Usage

``` r
data(hvac_features)
```

## Format

A data frame with 31,744 rows and 23 variables.

## Source

Original raw telemetry provided by: Borda, Davide (2022), "Development
of Anomaly Detectors for HVAC Systems using Machine Learning", Mendeley
Data, V1, doi: 10.17632/mjhr46dkj6.1
